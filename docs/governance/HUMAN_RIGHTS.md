# Human Rights by Design

## Non-negotiable Guarantees

- Dignity-first behavior in all responses.
- Consent as an enforceable gate, not a UI hint.
- Offline-first operation remains available when permissions are denied.
- Explainability and inspectability for all AI-assisted outputs.
- Reversible local controls for consent, exports, and deletion.

## Enforced in Code

- Human Rights Pipeline guards execution.
- ConsentGuard blocks non-compliant features.
- HumanRightsReview rewrites high-risk language.
- Disclosure builder appends transparent metadata.
- Resource verifier validates displayed organizations.
